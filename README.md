# Ziz

I build desktop apps, developer tools, and interactive software — mostly for macOS and iOS.

I care about performance, thoughtful interfaces, and small details that make a tool easier to use. Most of my projects start as something I want to use myself.

[Portfolio](https://buzzword365.github.io) · [Repositories](https://github.com/buzzword365?tab=repositories)

## How I approach projects

Build something useful, keep the interface considered, test real interactions, and be clear about what still needs work.

The repositories contain source code, setup instructions, and project-specific limitations. They are independent projects at different stages of development.
